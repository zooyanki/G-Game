# Карта мира (Tiled)

Редактор: [Tiled](https://www.mapeditor.org/).

## Файлы

- `world.tmj` — карта 60×60, тайл 16×16
- `tileset.png` — 8 тайлов в ряд

Игра читает копии из `public/map/` (Vite static). После правок в `map/` скопируйте оба файла в `public/map/`.

## Слои

| Слой | Назначение |
|------|------------|
| `ground` | Видимая земля (песок, трава, вода, деревня) |
| `collision` | Любой ненулевой тайл — стена для Arcade |
| `objects` | Спавны и цели миссий |

## Типы объектов (`type`)

| type | Свойства | Смысл |
|------|----------|--------|
| `spawn` | — | Старт героев (центр объекта) |
| `enemy` | `missionId?` | Враг; если есть `missionId`, считается для миссии kill |
| `goal` | `missionId`, `kind` = `reach` \| `fetch` | Зона цели (прямоугольник) |
| `item` | `itemId` | Подбираемый предмет |
| `chest` | — | Сундук: подойти и нажать удар/пробел, внутри 1–4 монеты |

## Зоны карты

- Юг — берег (песок), старт
- Центр — лесная тропа
- Север — деревня (сдача предметов)
